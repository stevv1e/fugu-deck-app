## Коротко о проекте

Fugu Deck — клиент AI-агентов для Android и Windows с общим серверным пространством. Пользователь работает с чатами, проектами, репозиториями, медиа, Google Drive и Git-модулями, а чувствительные действия подтверждает ключом своего устройства.

Основные свойства:

- одинаковые пространства, чаты и настройки моделей на подключённых устройствах;
- 44 облачные модели в каталоге, роли моделей и fallback;
- Android и Windows на общем React Native/Expo интерфейсе, Windows дополнительно использует Electron;
- вход Windows по короткому коду с подписанным подтверждением на телефоне, без Bluetooth и USB;
- DPoP, mTLS, PKCE и компактные JWS-подписи действий;
- изолированные Git-модули с pinned commit, SHA-256 и подписанным официальным каталогом;
- транскрибация аудио/видео, отчёты, генерация изображений и Google Drive;
- экспорт модулей и ручная E2EE-синхронизация без экспорта API-ключей.
