# История изменений Fugu Deck

Здесь публикуются заметные пользовательские и технические изменения. Планы на будущее находятся в [ROADMAP.md](ROADMAP.md), а не в списке завершённых изменений.

## 0.16.0 — 24 ноября 2026

[Скачать релиз](https://github.com/stevv1e/fugu-deck-app/releases/tag/v0.16.0)

- Добавлены фоновые обновления Android и Windows через подписанные Ed25519 update-манифесты.
- Перед установкой проверяются официальный Release URL, версия, размер и SHA-256 пакета.
- Windows получил прогресс загрузки, отложенный перезапуск и запуск только проверенного installer handle.
- Android получил прогресс, отмену и открытие системного установщика без скрытой установки.
- Windows build теперь получает версию и commit из общего `VERSION`/Git SHA.

## 0.15.1 — 24 ноября 2026

[Скачать релиз](https://github.com/stevv1e/fugu-deck-app/releases/tag/v0.15.1)

- На Windows добавлены нативный выбор нескольких файлов, drag-and-drop и чтение больших файлов частями.
- Добавлены прогресс, отмена и повтор загрузки с подтверждённого сервером offset; при отмене частичный файл удаляется.
- Открытие и сохранение вложений на Windows работают через нативные приложения и системный диалог.
- Добавлены server upload status/cancel endpoints и проверки Unicode-имён, изменения файла, границ чтения и прав доступа к выбранным handles.
- Публичный CI теперь проверяет backend, mobile, keyguard cross-tests, action vectors, lint, web export и Electron.

## 0.14.1 — 23 ноября 2026

[Скачать релиз](https://github.com/stevv1e/fugu-deck-app/releases/tag/v0.14.1)

- Увеличен предел аудио/видео до 2 ГБ на Android, Windows и сервере.
- Добавлен выделенный FFmpeg media worker: видео потоком проходит через keyguard, а на транскрибацию отправляются только аудиофрагменты OGG.
- Исправлена обработка актуального формата изображений Gemini Interactions API.
- Сохраняются Gemini `thought_signature` при вызовах инструментов, что устраняет ошибки HTTP 400 после tool call.
- Опубликованы APK, Windows EXE и SHA-256; обновлён лендинг.

## 0.14.0 — 21 ноября 2026

[Скачать релиз](https://github.com/stevv1e/fugu-deck-app/releases/tag/v0.14.0)

- Восстановление маршрута ограничено проверенными внутренними адресами выбранного пространства.

## 0.10.0 — 20 ноября 2026

[Скачать релиз](https://github.com/stevv1e/fugu-deck-app/releases/tag/v0.10.0)

- Добавлены конструктор модулей, локальная отладка и атомарная GitHub-публикация.
- Официальный каталог подписывается Ed25519; пользовательские источники не получают доверие официальной подписи.
- Добавлены журнал безопасности, экспорт/импорт и ручная E2EE-синхронизация модулей.
- Добавлены загрузка в Drive, создание папок, отчёты по транскриптам и генерация изображений.
- Улучшено восстановление длинных ответов транскрибации Gemini.
