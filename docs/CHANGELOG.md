# История изменений Fugu Deck

Здесь публикуются заметные пользовательские и технические изменения. Планы на будущее находятся в [ROADMAP.md](ROADMAP.md), а не в списке завершённых изменений.

## 0.21.0 — 27 ноября 2026

- Поиск по базе знаний возвращает короткие доказательства вокруг совпадения. Полная заметка доступна агенту через `memory_read`, а пользователю — прежним нажатием на карточку.
- Добавлены `memory_verify` и `POST /api/memory/{id}/verify`: on-demand сверка с GitHub/GitLab, fresh/stale/unavailable, записанная и текущая ревизии, фрагмент текущего источника.
- В карточке заметки добавлены понятный статус, дата последней проверки и кнопка «Проверить актуальность».
- Проверка работает только через существующие Git providers; произвольный URL или SSH-доступ новому endpoint не добавлялся.

## Space 0.20.0 — 27 ноября 2026

- Добавлены `repo_map` и `read_symbol`: агент сначала получает карту и сигнатуры, затем читает конкретные диапазоны кода.
- Runs сохраняют шаги, SSE-события, usage, router metadata и tool checkpoints в SQLite. После перезапуска «Повторить» продолжает тот же run без повторного выполнения завершённых инструментов.
- Незавершённое write/danger-действие не повторяется автоматически; повтор `call_id` с другими аргументами запрещён.
- Добавлен opt-in `auto:auto` с детерминированными simple/code/complex/media-правилами. Ручной выбор и явные fallback не изменены.
- Добавлены offline и live quality/cost/latency evals. Offline baseline: router 4/4; на синтетических 20 файлах map на 76,45% меньше полного исходного текста. Это не production-benchmark моделей.

## main — Authenticode, ещё не выпущено

- Windows CI поддерживает Authenticode/SHA-256 с RFC 3161 timestamp для приложения и NSIS; Release без PFX и точного publisher завершается ошибкой.
- Перед обновлением или откатом клиент проверяет доверенную Authenticode-подпись и закреплённый subject издателя в дополнение к Ed25519/SHA-256; неподписанный или чужой EXE удаляется без запуска.
- Исправлена публикация `update-windows-beta.json` в pre-release.
- Для реального подписанного релиза ещё нужен сертификат издателя и проверка на Windows. Откат с первого подписанного релиза на старый unsigned EXE будет намеренно отклонён.

## 0.18.1 / Space 0.19.0 / Control Plane 0.12.0 — 25 ноября 2026

[Скачать релиз](https://github.com/stevv1e/fugu-deck-app/releases/tag/v0.18.1)

- Внутри чата добавлен переключатель **Инжиниринг/Общение**. Он сохраняет историю и вложения, а исходный инженерный проект запоминается на сервере для возврата с любого устройства.
- «Общение» по-прежнему не получает Git, SSH, MCP и память проекта; multi-model сценарий доступен только в инженерном режиме.
- Добавлены stable/beta-каналы с отдельными Ed25519-подписанными манифестами. Beta создаётся из GitHub pre-release и не может заменить stable без явного выбора.
- Control Plane отдаёт stable, beta и предыдущую stable-версию; старый ответ `latest`/`url` сохранён.
- На Windows добавлен явный откат на предыдущий stable: старый установщик скачивается отдельно, проверяется по подписи/SHA-256 и запускается только после подтверждения.
- Обычное обновление по-прежнему отклоняет старые версии. Android downgrade поверх установленного приложения не обещается из-за ограничения `versionCode` в ОС.
- Authenticode и реальная проверка обновления/отката на устройствах остаются отдельными пунктами приёмки.
